## 4. Hướng dẫn sử dụng cho AI Agent (System Prompt & RAG Integration)

- **Cấu trúc phân trang:** Mọi file Markdown đều được phân định rõ ràng theo từng trang gốc bằng tiêu đề ## Trang X kèm đường kẻ phân tách ---. AI Agent có thể dễ dàng trích dẫn số trang chính xác của nguồn tài liệu khi trả lời.
- **Tính toán vẹn:** Giữ nguyên các đề mục, bảng số liệu, danh sách gạch đầu dòng và toàn bộ thuật ngữ tên thuốc quốc tế (INN), cơ chế tác động, chỉ định, chống chỉ định, dược động học (hấp thu, phân bố, chuyển hóa, thải trừ).
- **Phù hợp cho Vector DB / RAG:** Định dạng Markdown chuẩn này tối ưu hoàn toàn cho các framework như LangChain, LlamaIndex, Haystack khi thực hiện chunking theo ## Trang X hoặc theo Header.
